# Wandr — AI Travel Companion

## Setup

1. Install dependencies: `npm install`
2. Copy `.env.example` to `.env.local` and add your Anthropic API key
3. Run locally: `npm run dev`
4. Open http://localhost:3000

## Deploy to Vercel

1. Push this repo to GitHub
2. Import the repo on vercel.com
3. Add `ANTHROPIC_API_KEY` as an environment variable in Vercel
4. Deploy — done!

## Editing

Edit `src/components/WandrApp.jsx` to change the app.
Commit to GitHub → Vercel auto-deploys in ~30 seconds.
